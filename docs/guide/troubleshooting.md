# Troubleshooting

| Message (or symptom) | Meaning | Fix |
|---|---|---|
| `test interpreter ... cannot import pytest` | The Python chosen for your tests has no pytest. | Install pytest in your project's environment, or pass `--test-python` with one that has it. |
| `no interpreter for your tests` | No `.venv/`, `venv/` or `env/` in the repository, and no usable `python3` on PATH. | Pass `--test-python PATH`. |
| Before-checks fail with import errors | The test Python lacks your project's dependencies. | Point `--test-python` at your project's environment. |
| `endpoint does not serve model ...` | The server lists other model names. | Pass `--model` with a name it lists. |
| `STATEFRAME_CONTEXT_TOKENS=N requires a live server slot of N tokens; observed M` | The server's slot size differs from the configured context size (they must be equal; `--kv-unified` reports the total). | Start the server with a slot of exactly N (`-c` = N x `--parallel`, without `--kv-unified`), or unset the setting. See [Context size](running.md#context-size). |
| Slot too small / refused server | Each server slot needs 65,536 tokens (the default; see Context size in running.md). | For llama.cpp use `-c 65536` times your `--parallel` count. |
| `Context size has been exceeded` from the server when runs overlap | With `--kv-unified` all slots share one cache, and each slot reports the total, so the slot check passes while concurrent runs overflow it. | Start the server with `-c 65536` times `--parallel` (for example `-np 4 -c 262144 --kv-unified`). |
| Remote endpoint refused | Only loopback endpoints are allowed by default. | Set `STATEFRAME_ALLOW_REMOTE_ENDPOINT=1` if you accept that code leaves the machine. |
| Stops asking for `--target` / `--edit` | The repository has more than 200 source files. | Name the starting file and the other files the change may touch. |
| `unconsumed STATEFRAME settings: ...` (HARNESS_CONTRACT) | A profile sets a switch this engine does not read. | Remove it or fix its name. |
| Stops with a refusal about the prompt budget | The task state no longer fits 33,344 tokens (very long tasks, changes of around 10+ files). | Split the task; the partial result is saved. |
| Run ends with `STALLED` after repeated unchanged reads | A completed batch made entirely of unchanged reads costs one no-progress step, but repeated batches still reach the limit. | Inspect the last frame with `stateframe inspect <run-dir> --send N --frame`. Check whether the relevant source is visible and whether the current failing check gives a usable `file:line`; setup and collection failures, and failures without a source location, do not activate code bookmarks. See [Multi-file source and repeated reads](running.md#multi-file-source-and-repeated-reads). |
| `ERR:FrameFit5ImpossibleMinimum`, or `token counting unavailable: using conservative estimate` | The server has no `/tokenize` endpoint (for example Ollama or hosted APIs), so the engine estimates token counts conservatively, and even the minimum frame looks too big. | Use llama.cpp, or run a local llama.cpp tokenizer and set `LLAMA_CPP_TOKENIZE_URL`. A scripted endpoint needs `"tokenize": {"mode": "ok"}`. |
| Checks report FAIL with exit 71 and `sandbox-exec: execvp() ... Operation not permitted` | The checks could not start: the sandbox could not launch the test Python. We have seen it when StateFrame was started from a process that was itself sandboxed. It is not a test failure. | Run StateFrame from a normal terminal session. |
| `bwrap is required on Linux for StateFrame's command isolation (install it: sudo apt install bubblewrap)` (installer) | Linux needs bubblewrap for the sandbox. | `sudo apt install bubblewrap`, then run `./install.sh` again. |
| `test interpreter /usr/bin/python3 ... cannot import pytest` on Ubuntu | The stock `python3` (3.10 on Ubuntu 22.04) has no pytest and is older than StateFrame needs. | Install Python 3.11 or newer for StateFrame (`sudo apt install python3.11 python3.11-venv`), and pass `--test-python` with your project's environment. |
| Long waits per turn with a remote server | Token counting goes over the network. | Run a local tokenizer and set `LLAMA_CPP_TOKENIZE_URL` (QUICKSTART). |
| Requests rejected for context overflow after a tokenizer outage | The fallback estimate undercounted. | Keep the tokenizer up for the whole run. |
| `stateframe resume` refuses | The run already finished, its records are damaged, or a different engine version is installed. | The message names which; a different engine needs the original install. |
| `resume-divergence.json` appears | A rebuilt request differed from its record; the run continued live from there. | Nothing to do; the file says where. |
| `REFUSED SHELL_OFF` or `READ_ONLY_POLICY` | Shell is disabled, or the read-only inspection grammar does not admit the command. | Choose an appropriate `--shell` mode at run start, or use a native read tool. |
| `REFUSED DENIED_PROGRAM` | The standard-mode filter denies a program, or a command or timeout is invalid. | Check the command and settings. Use `--shell-allow PROGRAM` only when you trust it; the sandbox remains the security boundary. |
| `REFUSED ASK_DECLINED` | A command outside the allowed set was declined or its confirmation timed out. | Approve it in chat, use an explicit `--shell-allow`, or turn off `--shell-ask` for a trusted run. |
| `REFUSED NETWORK_OFF` | A detected dependency install needs network access. | Start a run with `--shell-network full` if the install is intended. Add the dependency to the project declaration for later runs. |
| `REFUSED JOB_LIMIT`, `UNKNOWN_JOB` or `BAD_CONDITION` | Four jobs are running, the job ID is unknown, or a wait/output argument is invalid. | Stop or wait for a job, use an ID shown in the `jobs` section, and check `until`, literal `text`, `port` and timeout ranges. |
| `REFUSED SANDBOX_UNAVAILABLE` | The required `sandbox-exec` or bubblewrap boundary could not start. | Run from a host terminal with the platform sandbox available. The tool does not fall back to unsandboxed execution. |
| `REFUSED TIMEOUT` or `CLEANUP_FAILED` | A command exceeded its wall limit, or its process tree could not be stopped and checked. | Inspect retained output for a timeout. A cleanup failure stops the run; inspect the run and do not assume its effects were reconciled. |
| `REFUSED PROTECTED_TEST`, `NOT_EDITABLE`, `NEW_FILE_FORBIDDEN` or `OUTSIDE_WORKSPACE` | A file operation or shell effect crossed a protected-test, edit-scope or working-copy boundary. | Keep the change inside the task's declared paths. Shell effects outside scope are restored to their pre-call state. |
| `REFUSED PATH_NOT_FOUND`, `DESTINATION_EXISTS`, `SYMLINK`, `IS_DIRECTORY` or `UNSUPPORTED_MODE` | A delete or move source is missing, linked, a directory or an executable move; an identical destination also counts as an existing destination. | Use a contained repository-relative regular-file path and a new destination. Use `file_delete` to remove an executable. Refusals have the form `REFUSED <CODE>: <reason>`. |
| Command effects refuse with a workspace size-limit error | Reconciliation found a file over 16 MiB, over 256 MiB of total regular-file data, or more than 20,000 entries in the pre-call or post-call workspace. | Reduce the working copy or command output files and start a new run. Effects are not promoted when the bound is exceeded. |
| Executable-bit changes are restored | The sealed candidate does not transport executable-mode changes. | Keep generated files non-executable; use `file_delete` for intentional executable removal. `file_move` refuses executable sources. |
| `plain loop does not support git, web or custom tools` or `REFUSED PLAIN_UNSUPPORTED` | The plain loop was selected with unsupported tools or a background shell call. | Use the composed loop, or start plain mode with `--git-tool off --web off`, no `--tools`, and foreground shell only. Lean mode is not supported by the product profile. |
| `REFUSED NOT_A_GIT_REPO`, `EXCLUDED_PATH`, `BAD_REVISION`, `MISSING_OBJECT` or `BAD_ARGUMENT` | The Git view is unavailable, a path is excluded, or the request cannot be read from pinned history. | Use the run's copied product paths and a valid available revision. Missing objects are not fetched. |
| `REFUSED WEB_REFUSED_ADDRESS`, `WEB_REFUSED_SCHEME`, `WEB_REFUSED_PORT` or `WEB_DOMAIN_NOT_ALLOWED` | A web URL or redirect violates public-address, scheme, port or domain policy. | Use a public HTTP(S) URL on port 80 or 443, within any `--web-allow` list. |
| `REFUSED WEB_TOO_LARGE`, `WEB_CONTENT_TYPE`, `WEB_TIMEOUT` or `WEB_HTTP_ERROR` | The response exceeds a limit, is not readable text, times out or fails HTTP/transport checks. | Use a smaller text page or another public source. The 20-second deadline and size caps are fixed. |
| `REFUSED BAD_ARGUMENTS` or `TOOL_CHANGED` | A custom command's arguments fail its schema, or its executable changed since the run started. | Match the declared arguments. Start a new run after changing a tool definition or executable. |
| `external operation ... requires --replay-external` | Resume reached a full-network, host-mode or external custom operation. | Reconcile the outside effect first. Pass `--replay-external` only if repeating it is acceptable. |
| `operation ... may or may not have happened` or `environment diverged at tool call ...` | A tool lacks a completed tape record or a repeated local operation does not match its recorded exit, workspace or environment. | Inspect the run and outside systems. Start a new run after reconciling; resume refuses to guess. |
